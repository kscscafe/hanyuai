## 3. 決定事項・ナレッジ

### Apple 審査ルール（3.1.2 サブスク要件）
- **メタデータ要件**：App Store の説明文に EULA / プライバシーポリシーへの**機能するリンク**が必要
- **アプリ内要件**：サブスクのタイトル・期間・価格・EULA・プライバシーポリシーリンクが**Paywall画面に**全部揃っている必要がある
- 説明文側だけ直してもアプリ内が不足だと次回また落ちる（Apple は同じ案件で複数指摘を分割で出す傾向）
- Apple標準EULAを使えば自社EULA作成は不要。リンクは `https://www.apple.com/legal/internet-services/itunes/dev/stdeula/`

### Build 番号運用
- リジェクト後の再提出は必ずビルド番号インクリメント必須
- リジェクトされたバイナリと同じ番号では再アップロードできない
