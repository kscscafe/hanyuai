## 3. 決定事項・ナレッジ

### IAP系
- **サブスクリプショングループのローカリゼーションは必須**。子IAPのローカリゼーションが埋まっていても、グループ側が空だと「メタデータ不足」が抜けない
- **`.storekit` ファイルでストアフロント固定**するには `settings._storefront: "JPN"` を追加する。Editorメニューから設定する方法が新しめのXcodeでは効かないことがある
- **StoreKit設定変更後は Clean Build Folder（⇧⌘K）必須**。シミュレーター削除＋再ビルドだけだと反映されない
- **消耗型IAPの「審査へ提出」ボタンは押さない方が良い**。バージョン同梱で出したいなら「送信準備完了」のままにしておく（押すと「審査待ち」に飛んで取り消し不能になる）
- **App Store ConnectのIAP選択ダイアログは「送信準備完了」状態のIAPしか表示しない**

### App Store審査系
- v1.1.0 の Apple リジェクト原因は「**IAP商品をバージョン提出時に紐付けていなかった**」だった
- バイナリをアップロードするまで「アプリ内購入とサブスクリプション」セクションは表示されない
- IAP単体 + 新規バイナリの組み合わせでないと審査が始まらない仕様

### コラボレーション
- キャラ × 課金UIは分離する（HanYuAIの世界観保護）
- Rikuto は iOS Native 外注エンジニア・コード実装のみ。Archive・申請・リリースは杉崎単独
